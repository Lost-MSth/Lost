# 卡凯坦 - 赌博圣传说

カカイタン – ギャンブルの聖伝説 v1.1.0

三狐黄矢

## 类型

- 1.09 GB
- SLG、小游戏
- 现实世界
- 单线

## 评价

一次通关大概不到 1 小时（不包括成功尝试修改存档的时间），全收集。

总体而言不错，美术好看是优点，游戏重复性高是缺点。耗时较少，建议在开挂的情况下试试。

剧情简单易懂，男主作为赌圣去挑战赌城的三个女主，一个个攻略完后去找大 boss，结果她溜走了，应该是留下后作伏笔了。

游戏难度不高但是费手费眼，玩起来很累，三个小游戏分别是记忆翻牌配对、连连看、找骰子点数，加上了一些干扰效果和技能。

H 事件算多的，普通 CG 也不少也很色气。玩法纯爱正常。画风中上偏上，真的色爆了，HCG 是短动画。无配音，有一点音效。

再吹一遍，这个游戏对我来说的最大亮点就是美术，画的真的很色气，三个女主一个比一个风骚，画风太赞了。

## 破解

Godot 游戏，资源未加密，GDRE_tools 可以反编译，看资源。

存档比较特殊，针对 `saves/system/chips_balance.ucsav` 的结构按顺序是这样的：

1. 4 bytes 的 magic `USCV`。
2. 1 byte 的 flag3 存档类型，应该是 `1`。
3. 32 bytes 的 HMAC-SHA256 签名。Key: `77BA7F51B7CDD55D88298007B0B53F3D8AA90E96CE345A18A22B4800E7A32B5C`。对后面的 GZIP 数据签名。
4. GZIP 数据。

至于签名的 Key 怎么获取，我是用 dnSpy 动态调试拿到的，先命令行添加参数 `-d` 进入调试模式，再 attach 下断点。

解完后应该是 JSON 数据，改钱就行了，这样就不需要大量重复打小游戏了。
