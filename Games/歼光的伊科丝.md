# 歼光的伊科丝

Radiance of Annihilation -Disorder Eclipse- 殲光のイクス-Disorder Eclipse- v1.0

クレージュアクセル

## 类型

- 2.53 GB
- ~~RPG~~、ADV
- 架空世界、科幻
- 单线

## 评价

看完一遍也就两小时。

总体而言质量还行，当然这根本就称不上是游戏，而是一个漫画播放器，感觉不如去某个粉红色软件上找到漫画版然后快速看了，要配音的话好像听说这玩意有动态漫画。

剧情简单易懂，苦主找到了作为兵器的女主，让她执行各种任务，细心呵护感情，然后被不满的黄毛抓到女主狠狠调教，女主最终堕落为黄毛的玩物，世界完蛋了。

说了不是游戏了，无任何选项，点点点点到底为止。当然我想吐槽一点，回想系统疑似就是设立了一堆存档点然后跳过去……

全程 H 事件。类型基本是以 NTR、凌辱、调教、洗脑为主的，另外请注意其带有 futa、轻度脱粪、人体改造等元素。画风上等偏上，HCG 静态（吐槽一下图片占了 2.1 GB）。有配音，有音效。

说到底，极品画风、超色的紧身衣、调教类玩法是我玩这个东西的动机，我要是知道这玩意是个漫画，估计直接就去看 CG 图了。不得不说这位画师还是很厉害的，女主的形象真的是典型的战斗服调教对象，对上 XP 这件事相当的重要。

## 破解

数据有加密，又是那个只防君子的 PNG 头加密，解密脚本核心部分如下：

```python
key = bytes.fromhex('5dc8f814973c73a264071013d2dfd028')

def decrypt_file(path):
    if path[-4:] != 'png_':
        return
    with open(path, 'rb') as f:
        data = f.read()
        if data[:16] != b'RPGMV\x00\x00\x00\x00\x03\x01\x00\x00\x00\x00\x00':
            raise Exception('WTF!')

        body = data[16:]
        r = b''
        for i in range(16):
            r += (body[i] ^ key[i]).to_bytes(length=1, byteorder='little')

    with open(path[:-1], 'wb') as f:
        f.write(r + body[16:])
```
